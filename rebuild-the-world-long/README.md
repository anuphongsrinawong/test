- คลิปพรีวิวเรนเดอร์ที่เครื่องคลาวด์ด้วย CPU (ไม่มีการ์ดจอ) ที่ 1280x720 24fps
- **เสียงพากย์เป็นฉบับร่างฟรี edge-tts (en-US-AndrewNeural)** เพราะเครื่องนี้ไม่มีคีย์ ElevenLabs และไม่ได้ใช้เครดิตเลย
  - ฉบับจริง: พากย์ด้วย Liam (`TX3LPaxmHKxFdv7VOQHJ`) ตั้งไว้ใน `longkit.js` แล้ว ประมาณ 0.45 เครดิต/ตัวอักษร
    (01.01 ~8,700 ตัวอักษร ≈ 3,900 เครดิต, 01.02 ~7,700 ≈ 3,500 เครดิต) ต้องถามก่อนเพราะเกินงบที่เหลือของซีรีส์สั้น
- เสียงประกอบใช้คลัง ElevenLabs เดิมใน `series/rtw/sfx` ทั้งหมด ไม่ได้สร้างเสียงใหม่
- ไม่มีภาพจาก Codex ใหม่ ใช้ภาพโลกของซีโร่ที่มีอยู่ (`series/rtw/world`)
- รวมกลับ: คัดลอก `studio/` ทับ `toon3d_studio/` (ไฟล์ `lib/story.js` เป็นฉบับแก้ทั้งไฟล์ ตรวจด้วย `story.js.patch`)
